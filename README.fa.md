# راهنمای اجرای Momentum OS روی کروم (ویندوز)

این اپلیکیشن یک **وب‌اپ (PWA)** است؛ یعنی باید با یک **سرور محلی** اجرا شود، نه با دابل‌کلیک روی فایل HTML. کروم به‌دلایل امنیتی اجازه نمی‌دهد ماژول‌های ES و IndexedDB (دیتابیس محلی اپ) از مسیر `file://` اجرا شوند.

## ✅ روش ساده (پیشنهادی): دابل‌کلیک روی Momentum.bat

دو راه دارید:

**راه ۱ — دابل‌کلیک (ساده‌ترین):** وارد پوشهٔ `MyToDoList` شوید و روی فایل **`Momentum.bat`** دابل‌کلیک کنید. یک پنجرهٔ سیاه باز می‌شود، سرور بالا می‌آید و **کروم به‌طور خودکار** روی `http://localhost:5173` باز می‌شود. برای خاموش‌کردن اپ، فقط همان پنجرهٔ سیاه را ببندید.

یک کپی از همین فایل هم روی **دسکتاپ** گذاشته شده است (`C:\Users\silkroadnb\Desktop\Momentum.bat`)؛ پس حتی از دسکتاپ هم با یک دابل‌کلیک برنامه اجرا می‌شود — این فایل همیشه خودش وارد پوشهٔ درست پروژه می‌شود و دیگر خطای «پوشهٔ اشتباه» نمی‌گیرید.

**راه ۲ — از ترمینال:** حتماً اول وارد پوشهٔ پروژه شوید، بعد دستور را بزنید:

```bash
cd C:\Users\silkroadnb\Desktop\MyToDoList
npm start
```

> ⚠️ اگر `npm start` را از جای دیگر (مثلاً مستقیم از دسکتاپ) بزنید، خطای `ENOENT ... Could not read package.json` می‌گیرید، چون `package.json` فقط داخل پوشهٔ `MyToDoList` است.

## روش‌های دیگر

| دستور | کار |
|---|---|
| `npm start` | اجرای سرور + باز شدن خودکار مرورگر |
| `npm run dev` | فقط اجرای سرور (خودتان آدرس را باز کنید) |
| `npm run build` | ساخت نسخهٔ نهایی در پوشهٔ `dist/` |
| `npm run preview` | پیش‌نمایش نسخهٔ نهایی روی پورت 4173 |

## عیب‌یابی

**۱. صفحه خالی/خطا در کروم (ERR_CONNECTION_REFUSED)**
- قبلاً علتش این بود که سرور فقط روی IPv6 گوش می‌داد؛ الان در `vite.config.ts` با `host: true` روی هر دو پروتکل گوش می‌دهد. اگر باز هم پیش آمد: سرور در حال اجرا است؟ (`netstat -ano | findstr 5173`)، بعد مرورگر را با `http://127.0.0.1:5173` هم امتحان کنید.

**۲. خطای ENOENT — «Could not read package.json»**

```
npm error code ENOENT
npm error path C:\Users\silkroadnb\Desktop\package.json
npm error enoent Could not read package.json: ...
```

- این خطا ربطی به خود برنامه ندارد؛ یعنی دستور را از **پوشهٔ اشتباه** اجرا کرده‌اید (اینجا: از `Desktop` به‌جای پوشهٔ پروژه). فایل `package.json` فقط داخل `C:\Users\silkroadnb\Desktop\MyToDoList` است.
- راه‌حل: اول وارد پوشهٔ پروژه شوید، بعد دستور را بزنید:
  ```bash
  cd C:\Users\silkroadnb\Desktop\MyToDoList
  npm start
  ```
- راه‌حل همیشگی: روی `Momentum.bat` (در پوشهٔ پروژه یا روی دسکتاپ) دابل‌کلیک کنید؛ این فایل خودش وارد پوشهٔ درست می‌شود.

**۳. پورت 5173 اشغال است**
- سرور خودش پورت بعدی آزاد را انتخاب می‌کند (مثلاً 5174) — آدرس را از خروجی ترمینال بردارید. یا سرور قبلی را ببندید:
  ```bash
  netstat -ano | findstr :5173
  taskkill /PID <شماره‌ی PID> /F
  ```

**۴. فایروال ویندوز پیام داد**
- چون سرور روی همهٔ اینترفیس‌ها گوش می‌دهد، اولین بار ویندوز ممکن است اجازه بخواهد. برای استفادهٔ خانگی، تیک «Private networks» را بزنید و Allow کنید. اگر نمی‌خواهید، در `vite.config.ts` مقدار `server.host` را به `'127.0.0.1'` تغییر دهید.

**۵. صفحهٔ خالی بدون هیچ خطایی بعد از دابل‌کلیک روی index.html**
- طبیعی است — اپ فقط با سرور کار می‌کند. حالا به‌جای صفحهٔ خالی، یک پیام راهنما می‌بینید.

**۶. نصب به‌عنوان اپ دسکتاپ (اختیاری)**
- با نسخهٔ build‌شده (`npm run build` و `npm run preview`)، در کروم آیکون **Install** در نوار آدرس ظاهر می‌شود و اپ مثل یک برنامهٔ ویندوزی مستقل اجرا می‌شود. دیتای اپ (IndexedDB) کاملاً محلی روی همین مرورگر ذخیره می‌شود.

**۷. شورتکات/اپ نصب‌شده («Momentum OS» روی دسکتاپ) نسخهٔ قدیمی نشان می‌دهد**
- آن شورتکات، اپ **نصب‌شدهٔ PWA در کروم** است و نسخه را از کش سرویس‌ورکر خودش اجرا می‌کند؛ اگر قبل از به‌روزرسانی کد نصب شده باشد، نسخهٔ قدیمی (بدون گزینهٔ زبان) را نشان می‌دهد — حتی وقتی کد جدید آماده است.
- به‌روزرسانی: اپ شما از `http://localhost:4173` (نسخهٔ preview) نصب شده؛ پس اول `Momentum-Preview.bat` را اجرا کنید (سرور 4173 بالا می‌آید)، بعد اپ نصب‌شده را باز کنید — چند ثانیه بعد سرویس‌ورکر جدید را می‌گیرد و صفحه خودش رفرش می‌شود. سرور باید همان موقع روشن باشد.
- اگر نشد: در کروم `http://localhost:4173` را باز کنید، `F12` → تب **Application** → **Storage** → **Clear site data**، صفحه را رفرش کنید و در صورت تمایل دوباره Install کنید.

## تغییر زبان برنامه (فارسی/English)

در برنامه به **تنظیمات → زبان (Language)** بروید و بین «فارسی» و «English» جابه‌جا شوید. با انتخاب فارسی، کل رابط کاربری ترجمه شده و چیدمان به‌صورت خودکار **راست‌به‌چپ (RTL)** می‌شود؛ تاریخ‌ها هم به تقویم هجری شمسی نمایش داده می‌شوند. انتخاب شما در همین مرورگر ذخیره می‌شود و دفعهٔ بعد قبل از اولین رندر اعمال می‌شود (بدون فلش اشتباه جهت متن).

**زبان پیش‌فرض برنامه فارسی است** — بار اول هم مستقیم فارسی و راست‌به‌چپ باز می‌شود؛ اگر خواستید به English برگردید از همان کارت در تنظیمات عوضش کنید.
